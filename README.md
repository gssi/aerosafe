# Aerosafe static companion website

Open `index.html` directly in a modern browser. The package is fully static and self-contained: HTML, CSS, JavaScript, generated local data, downloadable workbooks, and CSV files only. It has no server-side component, package manager, external font, analytics service, or network dependency.

The site includes:

- the Aerosafe workflow;
- Table 7 and the mapped Tables A.13--A.17 control library;
- the complete IMVV construction/execution example;
- a six-phase guided-use mode with progressive checks and a final checklist-conformity record; and
- a dedicated first formative evaluation section generated from the questionnaire workbooks, including participant-profile data, 132 ratings, descriptive statistics, item/category explorers, qualitative feedback, limitations, and downloadable tables.

The questionnaire results concern an earlier Aerosafe artefact and are presented as formative co-design evidence. They do not independently validate the final framework, demonstrate operational effectiveness or completeness, establish ECSS compliance or qualification success, or show comparative superiority.
